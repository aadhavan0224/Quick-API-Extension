
# Quick API 🚀

Quick API is a lightweight Chrome extension for testing REST APIs directly from your browser.

## Features

- Support GET, POST, PUT, PATCH, DELETE and HEAD methods
- Custom request headers
- Bearer token authentication
- JSON request body
- API response preview
- Response status and headers
- Save API requests
- Request history
- cURL import and export

## Technologies

- HTML
- CSS
- JavaScript
- Chrome Extension Manifest V3
- Fetch API

## Installation

1. Clone this repository.
2. Open Chrome.
3. Visit chrome://extensions/
4. Enable Developer Mode.
5. Click Load unpacked.
6. Select the project folder.

## Usage

1. Open the Quick API extension.
2. Enter an API URL.
3. Select an HTTP method.
4. Add headers or request body if required.
5. Click Send.
6. View the response.
